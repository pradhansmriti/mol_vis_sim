# README preview maintenance

The user wants the README preview kept current as the platform evolves.

- After changing visible interface content, layout, or interactions, capture a fresh screenshot of the running local application and replace `docs/images/workspace-preview.jpg`.
- Keep the preview embedded near the top of `README.md` using its repository-relative image path, and update its capture date.
- Use a clean, representative state without private data, absolute local paths, or unrelated browser content. Do not include user-supplied force-field files in Git.
- Inspect the actual screenshot before finishing. Include the screenshot refresh in the same commit as the related interface changes when committing is requested.
- For changes with no visible interface impact, keep the existing screenshot.
